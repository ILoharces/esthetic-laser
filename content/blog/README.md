# Cómo publicar en el blog (SEO local)

Este archivo **no** se publica como artículo. Úsalo como guía cada vez que escribas desde `/admin`.

## Antes de pulsar Publicar

1. **Título = búsqueda.** Ejemplo bueno: `Presoterapia en Pamplona: para qué sirve`. Evita `5 tips de belleza`.
2. **Descripción SEO:** 150–160 caracteres. Resume la pregunta que responde el artículo e incluye Pamplona si encaja.
3. **Imagen de portada** obligatoria, con **texto alternativo** descriptivo (no “imagen1”).
4. **Servicio relacionado:** elige depilación, presoterapia, Hydroface o general. Así el artículo enlaza al servicio y a reservar cita.
5. **Borrador:** actívalo si aún no está listo. Desactívalo para que salga en `/blog` tras el build (1–3 minutos).

## Cómo escribir el texto

- Un solo H1 (el título del panel). En el cuerpo usa H2 y H3.
- Responde dudas reales: cómo funciona, para quién, qué se siente, cuántas sesiones, dónde estáis.
- Nombra **Pamplona** de forma natural (dirección, barrio, Eroski), no en cada frase.
- Cierra invitando a reservar. No copies la tabla entera de precios.
- Frases cortas. Tú de “usted” o “tú”, pero no mezcles.

## Temas que sí atraen clientas

- Depilación láser diodo en Pamplona: cómo funciona y para quién
- Bonos y zonas (chica/chico), sin listar todos los precios
- Presoterapia: hinchazón, retención, cuándo se nota
- Hydroface: diferencia con una limpieza facial
- Preguntas frecuentes + cómo llegar (Ctra. San Sebastián / Eroski)

## Tras publicar

Espera 1–3 minutos y recarga `https://yoliestheticlaser.com/blog`. Si no aparece, el build de Netlify puede haber fallado: avisa a quien mantiene la web.
